# Catch The Lightning

## Мне так хочется, чтоб стала ты моей!

Визуализация желаемых результатов - уже достигнутых или досигаемых, должно помочь не упустить смысл и воодушевлять на достижение новых. 
Не трекер привычек, не список дел, а **витрина достижений**.

- Создавай достижение и условия для его выполнения. Чем детальнее, тем точнее подсчитать процент реализации.
- Не нужно выискивать их в куче - каждой сфере своё место.
- Не все достижения равноценны - задай ценность для каждой. Другие сразу поймут, насколько ты крут - без лишних слов.

### С чем имеем дело?

_Группы_ - способ оградить одни достижения от других.

_Цели_ - конечная цель, мечта, дорога до которой занимают другие мелкие достижения.

_Достижения_ - каждое со своим названием, описанием, списком условий для реализации. Одни достижения требуют выполнения сначала других - путь от начала к цели. Для удобства разные достижения можно присвоить группе. Достижения не равноценны друг другу, какие-то ценнее.

## Ключевые цели проекта

1. CRUD достижений с локальной БД.
2. Фильтрация по категории и статусу.
3. Статистика: количество, процент выполнения.
4. Валидация в диалогах добавления/редактирования.
5. Смена темы (светлая/тёмная) с сохранением.
6. Экспорт/импорт данных в JSON.
7. Клиент для синхронизации с удалённым REST API (для демонстрации понимания клиент-серверного взаимодействия).
8. Глобальный обработчик ошибок и логирование.

## Структура

Проект разделён на ядро приложения, функциональные модули Dashboard и слой
Avalonia-представлений. Ядро не зависит от конкретных экранов и содержит доменные
модели, доступ к данным, сервисы и общие MVVM-абстракции.

```
CatchLightning
│
├─App.axaml / App.axaml.cs       : Инициализация Avalonia и главного ViewModel
├─Program.cs                     : Точка входа и настройка Avalonia-приложения
├─MainWindow.axaml(.cs)          : Главное окно приложения
├─AppConfig.cs                   : Чтение конфигурации приложения
│
├─Core
│   ├─Abstractions               : Общие интерфейсы и контракты
│   │   └─Presentation           : BaseViewModel, команды и медиатор
│   ├─Models                     : Доменные сущности и модели фильтрации
│   ├─Infrastructure             : EF Core, SQLite, DbContext и репозитории
│   └─Services                   : Операции над сущностями и валидация
│
├─features
│   └─Dashboard
│       ├─Model                  : MainWindowViewModel и взаимодействие сущностей
│       ├─Achievement
│       │   ├─Model              : ViewModel категорий, целей и достижений
│       │   └─Presentation       : Представление страницы категорий
│       └─NavigationPanel        : Навигационная цепочка и её преобразования
│
├─Migrations                    : Миграции EF Core и снимок модели базы данных
├─appsettings.json              : Настройки и строки подключения
└─sqlite.db                     : Локальная база данных SQLite
```

Описание уровня [Models](./Core/Models/DomainLogic.md)


## Зависимости

**Фреймворк:** .NET 10.0

**Пользовательский интерфейс (Avalonia):**
- `Avalonia` – кроссплатформенный UI-фреймворк
- `Avalonia.Desktop` – поддержка десктопных платформ
- `Avalonia.Themes.Fluent` – тема оформления Fluent
- `Avalonia.Fonts.Inter` – встроенный шрифт Inter
- `AvaloniaUI.DiagnosticsSupport` – диагностика (только для Debug)

**Доступ к данным:**
- `Microsoft.EntityFrameworkCore.Sqlite` – провайдер EF Core для SQLite
- `Microsoft.EntityFrameworkCore.Tools` – инструменты для миграций

**Конфигурация:**
- `Microsoft.Extensions.Configuration.Json` – чтение `appsettings.json`
- `Microsoft.Extensions.Configuration.EnvironmentVariables` – чтение переменных окружения
